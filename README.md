# ToolNest AI — starter website

This is a zero-cost static starter for an AI-tools + digital-products business.

## Files
- `index.html` — homepage
- `style.css` — responsive design
- `script.js` — starter browser tools

## Next steps
1. Deploy the folder to Cloudflare Pages.
2. Create a payment account (e.g. Gumroad or Stripe, subject to eligibility).
3. Replace the placeholder Buy button with the real checkout URL.
4. Add real AI API functionality only after the free tools and traffic model are validated.
5. Add privacy/terms pages before collecting user data or running paid traffic.

The current tools are templates, not connected to an AI API yet.
